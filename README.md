# Airbnb Clone - Zaio Capstone Project

A fully functional full-stack Airbnb clone built as the final capstone project for the Zaio Full Stack Developer course.

## Live Demo
* **Deployed Application:** https://gund-airbnb-clone.onrender.com

## Features
* Responsive property browsing and search interface.
* Dynamic property detail views and navigation flow.
* Clean component-based architecture.

## Tech Stack
* **Frontend:** React, JavaScript, HTML5, CSS3
* **Backend:** Node.js / Express
* **Deployment:** Render
